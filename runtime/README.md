# Arcadia Framework

`arcadia-framework` is a modular backend framework for Rust inspired by the
architecture and developer experience of NestJS.

It provides application modules, dependency injection, controllers, request
scopes, lifecycle hooks, HTTP middleware, guards, pipes, interceptors, filters,
WebSockets, microservice transports, OpenAPI integration, and testing helpers.

The procedural macros are provided by [`arcadia-macros`](https://crates.io/crates/arcadia-macros).

Repository: <https://github.com/azomura/arcadia-framework>
