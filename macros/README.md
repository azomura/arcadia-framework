## English

`arcadia-macros` provides the procedural macros used by
[`arcadia-framework`](https://crates.io/crates/arcadia-framework) for modules,
controllers, routes, and injectable providers.

### Install from crates.io

```toml
[dependencies]
arcadia-framework = "0.1.9"
arcadia-macros = "0.1.9"
```

```bash
cargo add arcadia-framework@0.1.7
cargo add arcadia-macros@0.1.7
```

### Git release

```toml
[dependencies]
arcadia-macros = { git = "https://github.com/azomura/arcadia-framework.git", tag = "v0.1.9" }
```

```bash
cargo add arcadia-macros --git https://github.com/azomura/arcadia-framework.git --tag v0.1.7
```

### Development branch

```toml
[dependencies]
arcadia-macros = { git = "https://github.com/azomura/arcadia-framework.git", branch = "dev" }
```

```bash
cargo add arcadia-macros --git https://github.com/azomura/arcadia-framework.git --branch dev
```

### Local clone

```toml
[dependencies]
arcadia-macros = { path = "../arcadia-framework/macros" }
```
