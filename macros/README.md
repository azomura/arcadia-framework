## English

`arcadia-macros` provides the procedural macros used by
[`arcadia-framework`](https://crates.io/crates/arcadia-framework) for modules,
controllers, routes, and injectable providers.

### Install from crates.io

```toml
[dependencies]
arcadia-framework = "0.1.4"
arcadia-macros = "0.1.4"
```

### Git release, development branch, or local clone

```toml
[dependencies]
arcadia-macros = { git = "https://github.com/azomura/arcadia-framework.git", tag = "v0.1.4" }
```

Replace the tag with `branch = "dev"` for development code or use
`arcadia-macros = { path = "../arcadia-framework/macros" }` for a local clone.

## Русский

`arcadia-macros` содержит procedural macros для
[`arcadia-framework`](https://crates.io/crates/arcadia-framework): modules,
controllers, маршрутов и injectable providers.

### Установка из crates.io

```toml
[dependencies]
arcadia-framework = "0.1.4"
arcadia-macros = "0.1.4"
```

### Git-релиз, development-ветка или локальный clone

```toml
[dependencies]
arcadia-macros = { git = "https://github.com/azomura/arcadia-framework.git", tag = "v0.1.4" }
```

Для development-кода замени tag на `branch = "dev"`, а для локального clone
используй `arcadia-macros = { path = "../arcadia-framework/macros" }`.
